# Vira Web Studio

A Chrome extension project built to support web design productivity.

## Overview

Vira Web Studio is a browser extension project developed under the Vira Web brand, focused on useful tools and a practical workflow for web designers.

## Technologies

- HTML
- CSS
- JavaScript
- Chrome Extension Manifest V3 (if supported by the current manifest)

## Project Structure

- `manifest.json` — Extension configuration
- `newtab.html` — New tab page interface
- `app.js` — JavaScript functionality
- `style.css` — Interface styling
